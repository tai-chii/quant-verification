# Numerai ニューラルネット探索の指示（Claude Code 用・2026-10-03 固定）

あなたは taichi の Numerai の作業を手伝う。作業フォルダは **このフォルダ（~/ワークスペース/作業層/検証/numerai）だけ**。
このフォルダの外のファイル（特に ~/ワークスペース/vault）は読まない・書かない・消さない。

## 目的（2026-10-03 改訂: 公式の診断を見て BMC を主に）
Numerai の本番の採点対象 `target` に対して、ニューラルネットの構造を探し、LightGBM の基準モデルに勝てるかを確かめる。
基準の公式の診断: CORR 0.0175・シャープ 1.21・**BMC −0.0011**（公開ベンチマークへの上乗せがほぼ0）。
**主な物差しは BMC**（`numerai_tools.scoring.correlation_contribution` で、公開ベンチマーク `v53_lgbm_ender60` に対する貢献。
ベンチマークの予測は numerapi で `v5.3/validation_benchmark_models.parquet` を data/ に取得して使う）。CORR は副の物差し。

## データ
- `data/` に features.json・train.parquet・validation.parquet がある（01_download.py で取得済み）。無ければ止まって taichi に伝える。
- 特徴量は features.json の feature_sets の **small か medium**（all はメモリ不足になる）。学習データは4エラに1つの間引きでよい。
- 学習の目的変数は `target` のほか、features.json の targets にある `target_ender` 系も候補にしてよい。**採点は必ず `target` で行う。**

## 分割（必ず守る）
- validation のうち target がある部分をエラ順に並べ、**前の2/3を「探索用」、後ろの1/3を「取っておく期間」**にする。
- 取っておく期間は、モデルを1本選び終わるまで一切使わない（読んで採点しない）。

## 探索のきまり
- 上限: **試行は20本まで、合計2時間まで**。どちらかに達したら止める。
- すべての試行を `results/nn_trials.csv` に1行ずつ記録する（日時・構造・ハイパーパラメータ・目的変数・探索用期間のエラごと相関の平均・標準偏差・シャープ）。悪い結果も消さない。
- 選び方は先に固定する: **探索用期間のエラごと BMC の平均が最大の1本**（ただし探索用期間の CORR の平均が基準の 0.0175 の半分未満のものは選ばない）。
- 乱数の種を固定する（再現できるように）。

## 最後に
1. 基準: `models/baseline_small.pkl`（02_train_validate.py で作成）。無ければ 02_train_validate.py を実行して作る。
2. 選んだ1本と基準を、**取っておく期間で1回だけ**採点する。エラごとの BMC と CORR それぞれの差（選んだ − 基準）の平均・標準誤差・比を出す。エラごとの成績は隣と強く似る（自己相関 約0.47）ので、標準誤差は12エラごとのまとまりで計算する。
3. 結果を `results/summary.csv` に1行追記し、モデルを `models/` に保存する。
4. 日本語で短く報告する: 試した本数、選んだ構造、取っておく期間での成績（基準との差・比）、判定（比が1未満なら「基準と区別できない」、1〜2なら「保留」、2以上なら「改善」。試した本数が多いほど割り引いて読む）。

## やってはいけないこと

- このフォルダの外での書き込み。ファイルの削除。
- 上限を超えて探索を続けること。
