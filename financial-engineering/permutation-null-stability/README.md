## 方法（要点）

- 題材: TSMOM20 の全15合算のドリフト除去後 t。組 = 銘柄×半年、pnl_adj = pnl − pos × μ_組 × 1e4、マスター日付ごとに有効銘柄の平均 d_t、t = mean/SE。
- 帰無 1 回 = 各銘柄で組内の日次対数リターンを並べ替えて価格を作り直し、同じ t。
- B ∈ {20,50,100,200,500,1000} × seed 20。seed ごとに 1000 回を順に生成し、先頭 B 回で z(B, seed) と帰無の 97.5 点。SD は seed 間。
- 理論値 √((1+z̄²/2)/B)（z̄ = B=1000 の平均 z）と比べる。

## 判定（事前固定）

- SD(z) < 0.1 になる最小の B を「基盤の既定値」として提案。
- B=500 で SD(z) ≥ 0.2 なら、既存の B=500 の判定の z は ±0.2 の幅を見込むと記録。
- 理論値との比は記述。
