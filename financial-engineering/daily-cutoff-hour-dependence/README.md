### 解釈

- (a) t = 1.03 で 2 に届かない → 事前登録の規則（t < 2 → 棄却）により **棄却**。前半で最良だった区切り（h=17）が、後半でも 5 区切り平均を有意に上回るとは言えない。
- (b) Spearman = 0.10 で順位も続かない。
- 一方で (c) の比が 0.89 と大きい: 年の中では区切りを変えると損益が年平均と同じ程度に動く（＝選び方で見かけは変わる）。しかし、どの区切りが「良い」かは年ごとに入れ替わり、半期ごとの順位にも残らない。
- (a) の z = 3.39 は観測の t が「24区切りから5つを無作為に選んだときの帰無分布」の上位 1% 以内であることを示す。しかしこれは「5区切りの中で前半最良を後半に当てる」というルールが帰無よりは強い、という弱い証拠でしかなく、水準の t が 2 を割る以上、系統的な依存の主張としては弱い。事前登録では両方の閾値を満たす必要があり、片方で判定が割れたため規則どおり棄却。
- **検証基盤の UTC 0 時区切りは、他の 4 区切りや無作為選択の 24 区切りと比べて系統的に不利ではない。**基盤の決まりを見直す必要はない。
- 捨てた案の数: 約 3（区切りごとに L を選び直す／区切り平均合図／H4 拡張）。
- 事前登録からの変更点: なし。
