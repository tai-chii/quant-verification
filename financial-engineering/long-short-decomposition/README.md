## 方法（要点）

- 規則（主）= ドンチャン簡略版 55/20（直前55日高値を上抜けで翌足から買い、20日安値割れで手仕舞い、売りは対称、損切りなし）。副 = TSMOM20（翌足のポジション = sign(c_t − c_{t−20})。日足は 20 日、暗号資産 H4 は 20 本）。コストは段階1の往復 COST_RT の半分を片道に（暗号資産は往復 30bp 相対）。
- 側の分解 = 日次純損益を pos=+1 の足（買い側）と pos=−1 の足（売り側）に分け、全足の平均 [bp/足] を「寄与」として出す（参考に持った足だけの平均も）。
- ドリフト除去 = 同じ評価期間の平均リターン r̄ × 露出を引く（買い側: −r̄、売り側: +r̄ を持った足に）。
- 群 = FX8 / トレンド7 / 暗号資産。群の平均は銘柄平均の等ウェイト。t は月クラスタ（月ごとに銘柄平均した系列の t）。
- 帰無 = 各銘柄の半年の組の中でリターンを並べ替え（ドリフトとボラは保つ）、B=500 回で側ごとの平均の分布 → z。
- 期間: 全期間（判定）、前半 <2017 / 後半 ≥2017（記述）。両規則に同じ分解。

## 判定（事前固定）

- トレンド7・暗号資産で、売り側のドリフト除去後 |z|<2 かつ 買い側 z≥2 → 「利益は買い側のドリフトではなく買い側の順張り」。
- 買い側もドリフト除去後 z<2 → 「利益は上昇相場の分」。
- FX8 は記述。群で結論が割れれば「群で割れる」と出す。
- 判定は主（ドンチャン簡略版）に付ける。副 TSMOM20 では上の 1 行目は恒等式により起こり得ない（上の「状態」3 を参照）。
