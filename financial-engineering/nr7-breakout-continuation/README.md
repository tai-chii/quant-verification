### 解釈

事前固定どおり **棄却**（前後半とも 差の z<2）。実務的な解釈は3つ:

1. NR7 の翌日に「最初 2 時間の向きに続く」という Crabel 1990 の主張は、FX8+XAUUSD H1 の 2008-2026 では支持されない。
2. そもそも NR7 翌日のレンジは広がらない（0.96 倍）。Crabel が株式先物（1980 年代）で見た「狭い日の翌日に拡大」は、現代の FX/金では消えている可能性が高い。
3. 全体で見ると差 z=2.03 と惜しいが、前後半に分けると前半で明確に消え（z=1.11）、後半は惜しいが届かない（z=1.91）。「前後半で安定」の条件を課した事前固定が有効に働いた。
