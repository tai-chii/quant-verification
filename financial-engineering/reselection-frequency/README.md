## 結果

判定: **ノイズ**（機械判定 "H0: 頻度は結論を変えない"・**解釈: ノイズ**）

- 結果ファイル: `results/Q177_result_20261010_021130.json`
- all15_all（判定行）: Spearman(f, 純損益) = -0.4、f=21 − f=252 の差の t = 0.17。基準 `|Spearman|<0.8 かつ |diff_t|<2` → H0。
- 群別・前後半（記述）:
  - all15_all: 純損益 [bp/日] の年平均は f=21: 0.42、f=63: 0.75、f=126: 0.70、f=252: 0.35（どれも t<1）。切替回数は f=21 で 47.1 回、f=252 で 11.1 回。
  - fx8_all: f によらず負（f=252 で平均 -0.57 bp/日、t=-2.22）。差の t=0.66。Spearman=-0.2。
  - trend7_all: f によらず正だが t<1.4。Spearman=-0.4。
  - all15_pre（〜2016）: Spearman=-1.0、差 0.66 bp（t=1.44）。頻度が高いほど良い方向だが有意でない。
  - all15_post（2017〜）: Spearman=+0.4、差 -0.29 bp（t=-0.52）。符号が反転するが、どちらも有意でない。
- **副次発見**: どの頻度でも帰無（選び直し時点でランダムに L を選ぶ）との z がすべて負（all15_all で -2.6〜-3.9）。実際の「窓内の平均純損益が最大の L を選ぶ」は、ランダム選択より悪い。pre では -4 以下、post では ±0.6 近辺に戻るので、「選択の楽観」は pre の 2010s 前半で特に悪く、post で消える。Q139（候補 J から選ぶ楽観）の裏返し: 選べば選ぶほど楽観が負に効く。

## Zarrabi 2017 との対応

Zarrabi ほか 2017（主張カード Zarrabi2017-1）は「FX テクニカルは期間全体では多くが有意でも、毎月選び直すと儲かり方が続かなかった」。本検証では、毎月（f=21）と毎年（f=252）の差は有意でなく、FX8 ではどの頻度でも負で f=252 が最も悪い。Zarrabi の「頻繁な選び直しは損」は本サンプルでは支持されない（有意ではないが符号は僅かに逆方向）。
