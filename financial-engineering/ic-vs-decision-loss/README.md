## 方法（要点）

- 予測器 1 本: x_t = 20 日リターン → y_t = 翌日リターン。セル = 銘柄 × 暦年（100 日未満は捨てる）。
- (a) IC = セル内 Spearman(x, y)、(b) 的中率 = 符号の一致率、(c) 純損益 = 「|x| > u（u = 片道コスト × 2）のときだけ sign(x) を翌日に持つ」規則のコスト後の日次純損益の平均（bp/日・休みの日は 0 で全日平均）。
- セル間の Spearman ρ(IC, 純損益)、ρ(的中率, 純損益)。帰無 = 翌日リターンを年内で並べ替え（予測は実データのまま）B=500 → z。
- 期間: 前半 2008〜2016 ／ 後半 2017〜2026。群: 全15・FX8・トレンド7（判定は全15）。

## 判定（事前固定）

- 前半・後半それぞれで: ρ(IC, 純損益) ≥ 0.5 →「IC は決定の損失を代理する」。ρ < 0.3 →「IC と純損益は別物」（Alonso を支持）。間は未確定。
- 前半と後半で割れたら未確定。帰無の z は記述（事前登録からの変更点: 帰無でも同じ翌日リターンから作るため ρ が機械的に高く、z は判定に不向き。Fable 承認 2026-10-09）。「境目」の集中割合も記述。
