# Q168 CPRO 本式（Yang 2026 TradeGrad の正格な実装）で順張りの参照日数を選んでも、翌年の最大下落は A と区別がつかない

事前登録: スクリプト冒頭の "測る前に固定" 節。Q166-C2 の接続（CPRO 本体の式で測り直す）を Q167 で本文入手確認後に実行した。土台は Q141（`../bad-period-weighted-selection/`）。

- スクリプト: `kensho_cpro_exact_q168.py`（自己完結・冒頭に仮説・定義・判定・捨てた案の数・知識の締め切り・委託の確かめ方・CPRO 式の単体テストを記載）
- データ: Q141 と同じ `data_<SYM>_D1_fromH1.csv`（FX8+トレンド7＝15銘柄・Dukascopy UTC 日足 2008-02〜2026-07）
- 実行: `python3 kensho_cpro_exact_q168.py`（B=300・9 秒）。試走は `--B 30`・`--smoke`（合成データ・判定には使わない）
- 結果: `results/Q168_result_<日時>.json`・`results/Q168_cells_<日時>.csv`・棒グラフ PNG

## 方法（Q141 と異なるのは D のみ）

- A・B・C・候補 L・選択窓 3 年・片道コスト段階1 は Q141 と同じ。
- D = CPRO 本式（Yang 2026 TradeGrad `src/evaluate.py` + `src/loss.py` を直接参照）:
  - 選択窓 3 暦年を暦年で区切り、各年に対し AR[%] = Σpnl_bp/100、MDD[%] = MDD_bp/100。
  - `ar_score = σ(0.11×(AR_pct − 20))`、`mdd_score = σ(−0.22×(MDD_pct − 15))`、`combined = 100×ar_score^0.5×mdd_score^0.5×gate`。
  - CPRO = 下位 ⌈0.3×N⌉ 窓の combined の平均（N=3 → 下位 1 窓 = 最悪の年）。
  - **gate=1 固定**（取引頻度ペナルティは LLM 設定依存で TSMOM に移すと恣意的）。
- 判定（事前固定）: 標本外 MDD の差（A−D）> 0 かつ年単位 t ≥ 2、純損益の差（D−A）の t > −2 → 支持。MDD の t < 2 → 棄却。それ以外 → 未確定。前後半それぞれで判定し、総合する。
- CPRO 式の整合: 単体テスト（`_unit_tests`）で AR=20・MDD=15 → combined=50、AR=100・MDD=0 → 98.2、AR=−50・MDD=50 → <1 を確認（Yang 2026 の GitHub 式と手計算で一致）。

## 結果（2026-10-09 Opus 実行・判定）

- 本番: `results/Q168_result_20261009_215340.json`（226 セル・B=300・9秒）。
- 機械判定: **棄却（確定）**。
- **D は前後半とも標本外の最大下落を A より深くする側に動いた**（符号が仮説と逆）。
  - 前半（t<2017、n=79）: A−D = **−28.7bp**（**t=−0.60**）。純損益 D−A = +0.19bp（t=+0.56）。
  - 後半（t≥2017、n=147）: A−D = **−45.4bp**（**t=−0.57**）。純損益 D−A = −0.70bp（t=−1.05）。
  - 全期間: A−D = −38.5bp（t=−0.78）。D は A より MDD が深いが差は有意ではない（|t|<2）。
- Q141 の近似 B・C との比較（同じ 15 銘柄・同じ窓・同じコスト、Q168 の実行で再現: Q141 と完全一致）:
  - B（下位20%平均）: 前半 +87.5（t=+0.72）・後半 −94.0（t=−2.15）→ 棄却（Q141 の再現）。
  - C（mean − MDD/日数）: 前半 +0.1（t=+0.01）・後半 +93.8（t=+2.35）→ 棄却（Q141 の再現）。
  - **D は B・C よりさらに下落を抑えない**。
- 選んだ L の中央値: A=70・B=50・C=78・**D=100**（D は中〜長期の L を好む）。CPRO の AR 参照 20% / MDD 参照 15% は株式用のため、FX の典型的な年次 AR（数％〜一桁）と MDD（1〜数％）で動かすと、どちらの σ も平坦な領域に落ちやすい → 候補間の差が付きにくいという副作用が考えられる。
- 多重比較: 目的関数 B/C/D × 指標 MDD/pnl × 期間 2 ＝ 12。判定は MDD × D × 2 期間 ＝ 2 本（事前固定）。D のどちらの期間でも |t|<2 で、どの切り方でも支持しない。

判定: **棄却**。CPRO の近似を本式に置き換えても、翌年の最大下落の浅さは A と区別がつかない。むしろ平均的に深い側に動く（符号差は有意ではないが安定）。Q141 の知見「順張りの参照日数という1次元の対象では、悪い時期を重くする選択は下落を予告しない」は、本式でも支持される。

## 限界

- gate（取引頻度ペナルティ）を 1 固定にした。Yang 2026 の論文設定（最低取引頻度・鋭さ）を TSMOM に写すと、長い L（取引が稀）を強く割り引く可能性があり、D の L 選好が短めに寄る。本検証では AR/MDD 本体の寄与だけを問うた。
- CPRO の参照値（AR_ref=20、MDD_ref=15）は株式向けの校正。FX 向けに再校正した場合の挙動は未確認（恣意的な調整を避けるため実行しない）。
- 選択窓を 6 年に拡張して ⌈0.3×6⌉=2 の設定にすることは、前半（<2017）の標本年が 2 年に減るため不採用（別の検証として立てるべき）。
- 選ぶ対象は参照日数 1 つ。複数パラメータや規則そのものを最適化する場面（TradeGrad のようなプログラムの修正）では結論が変わり得る。
