### 解釈

- **純損益（判定基準）**: 事前固定の判定規則（all15 前後半で |t|≥2 かつ |z|≥2）はどこも通らない。all15 で見ると前後半とも符号は負（損切りが足を引く方向）だが、ゼロと区別できない。TSMOM60 は既にモメンタム戦略で、保有中の順方向の進展を途中で切ると期待値が下がる方向に働く——という素直な読み方と整合する。Kaminski・Lo 2014 の「モメンタムがある時だけ損切りは期待値を上げる」の予測の裏側（「既に合図でモメンタムを拾っているときに、追加の損切りで期待値はさらに上がるか」）は、少なくとも TSMOM60 D1 15銘柄・2008〜2026 では **上がらない**。
- **最大下落（記述）**: 群・期間を問わず mdd_diff が正（損切り側が浅い）で、t も 2.84〜7.77 と大きい。保険としては確実に効く。k=2 のほうが削減幅は大きい（k=3 で +478、k=2 で +739）。
- **fx8 pre だけ net P&L の方向性が大きい**（diff_bp −1.09、t −1.84、z −4.32）。期間と群の交互作用で、判定基準の 4 本には入らない記述数値だが、「2017 年前の FX8 では損切りが明確に損」という傾向を示唆する。
