## 方法（要点）

- 規則 1 本（Korzan 式1）: 終値で 252 日リターン > 0 かつ c > SMA200 なら保有、それ以外は現金。翌日約定・片道コスト段階1・現金金利 0。
- 量（Q097 と同じ）: 日次純損益（bp）の累積和の最大下落 MDD、日次の下位 5% の平均 CVaR5。あわせて純損益の平均・買い持ち（コストなし）との差・露出・切替回数。
- 帰無 = 評価期間内のポジション列を 252 日以上（n−252 以下）循環シフト（露出と切替回数を保つ）。B=2000 本を無作為に（範囲が狭ければ全部）。
- 期間: 前半 2008〜2016 ／ 後半 2017〜2026 ／ 全期間（記述）。シフトは各期間の中で行う。

## 判定（事前固定）

- トレンド7 のうち、前半・後半とも MDD が循環シフトの浅い側 5% 以内の銘柄が 5 以上 → 「タイミングによる防御は複数資産で再現」。3 以下 → 「SPX 固有」。4 は未確定。
- 純リターンが買い持ちを上回るかは記述（Q097 と同じく判定に使わない）。

**解釈: 確定。** 防御（MDD・CVaR の両方）が帰無を明確に上回るのは株価指数（USTECH 両期間、US500 は下落のあった後半）に限られ、商品・BTC・為替では、規則の MDD は買い持ちより大幅に浅いが同じ露出の無作為なタイミングとも区別できない＝下落の軽さの大半は露出の低さ。株価指数ではボラティリティの集中（下落時に変動が大きい）と200日線割れが重なるためと考えられる（推測・未検証）。Q097（米国株100年で支持）と矛盾せず、その適用範囲を株価指数に限る結果。
