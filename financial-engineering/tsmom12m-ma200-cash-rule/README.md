## 方法（要点）

- 規則 1 本（Korzan 式1）: 終値で 252 日リターン > 0 かつ c > SMA200 なら保有、それ以外は現金。翌日約定・片道コスト段階1・現金金利 0。
- 量（Q097 と同じ）: 日次純損益（bp）の累積和の最大下落 MDD、日次の下位 5% の平均 CVaR5。あわせて純損益の平均・買い持ち（コストなし）との差・露出・切替回数。
- 帰無 = 評価期間内のポジション列を 252 日以上（n−252 以下）循環シフト（露出と切替回数を保つ）。B=2000 本を無作為に（範囲が狭ければ全部）。
- 期間: 前半 2008〜2016 ／ 後半 2017〜2026 ／ 全期間（記述）。シフトは各期間の中で行う。
