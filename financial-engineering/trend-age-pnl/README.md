## 方法（要点）

- 仮説: H: TSMOM60 の合図が最後に反転してからの経過日数 a を 3 区分（a≤10・11〜40・41 以上）に分けると、翌日の順張り粗利 [bp] は若い区分ほど高く、D=若−老>0。
- 定義: a: 合図の符号が直近で変わった日からの営業日数。粗利 = pos[t−1]·ret[t]·1e4（コストは区分で変わらないので粗利で測る。純損益は記述）。
- 測るもの: 年×銘柄の D=若(a≤10)−老(a≥41) [bp/日]（年単位 t・all15/fx8/trend7）、3 区分の平均。前後半。
- 帰無: a の区分ラベルを年内で並べ替え（perm_within）B=500 → D の帰無分布 → z。
- 多重比較: 判定は all15 の D の前後半 2 本。群別・3 区分の平均は記述。
- 捨てた案: 約3: a を連続量で回帰する（非線形の可能性）、反転の「大きさ」で分ける、H1 への移植。
- 先行研究チェック: WebSearch 2026-10-10「trend age days since signal flip trend following returns decay fresh signals stronger」: Quantpedia「Trend Breaks in Trend-Following Strategies」、arXiv 2607.01550「Introduction to the Trend-Following Puzzle」、CFM のノート。 合図の年齢の 3 区分を 15 銘柄・前後半・年内並べ替え帰無で測る形は未確認（追試＋条件の穴）。
