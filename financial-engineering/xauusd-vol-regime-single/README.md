# Q161 XAUUSD 単銘柄・直前20〜60日の実現ボラが高い日に翌日の順張り損益が下がるか（ドリフト除去・前後半）

事前登録: `kensho_q161_xauusd_single.py` の冒頭。親: Q159（`../vol-regime-trend-following/README.md`）の事後発見（主駆動源 XAUUSD）の単銘柄確認。Q142 → Q159 → Q161 と枝分かれ。

- スクリプト: `kensho_q161_xauusd_single.py`（自己完結・乱数は SEED 固定のラベル並べ替えだけ）
- データ: `検証/学問/金融工学/作業/FX/システムトレード/data_XAUUSD_D1_fromH1.csv`（2008-05〜2026-06・4719本）
- 実行: `python3 kensho_q161_xauusd_single.py`（B=500・約25秒）。試走 `--smoke`（合成データ・結果は `results/smoke_*`、判定には使わない）
- 結果: `results/Q161_result_<日時>.json`、`results/Q161_per_combo_<日時>.csv`

## 設定（事前登録）

- 規則2本: TSMOM60（60日リターンの符号で翌日を持つ）、DON55/20（Q152・Q159 と同じドンチャン・損切りなし）。片道コスト= COST_RT_XAU/2 = 0.3 USD／1 単位。
- ボラ窓3本: 20・40・60日（直前の対数リターンの標準偏差）。局面: 20・40・60日ボラ > 拡大窓の中央値（t を含まない・GARCH 不使用）。
- ドリフト除去: `pnl_adj = pnl − pos_prev × μ_bp`。μ_bp = +3.879 bp/日（XAUUSD の 2008-05〜2026-06 平均）を全期間で固定。帰無でも同じ μ_bp を同じ日に引く。
- 帰無: 局面ラベルを月ブロックで並べ替え（損益・ポジション・μ_bp 固定）、B=500、SEED=20261010。
- 期間: 前半 2008〜2016（n=2134〜2174）／後半 2017〜2026（n=2464）／全期間（n=4598〜4638）。

## 判定（事前固定・変更禁止）

6通り（2規則×3窓）各通りで:
- 主の通過: 全期間 `pnl_adj_diff` < 0 かつ |z|≥2 かつ 前後半 `pnl_adj_diff` の符号が共に負。
- raw の通過: 同じ条件を `pnl_diff`（ドリフト除去前）で満たす。

総合:
- 確認（支持） = 主の通過 ≥ 5/6 かつ raw の通過 ≥ 4/6
- 部分支持 = 主の通過 3〜4/6 かつ 全期間 `pnl_adj_diff` 負＆|z|≥1.5 が ≥ 4/6
- 棄却 = 主の通過 ≤ 1/6 かつ 全期間 adj 負＆|z|≥2 < 2/6 かつ raw も < 2/6
- 未確定 = それ以外

多重比較: 2規則 × 3窓 = 6通り。主判定は全期間 adj 6本（補助に raw 6本と半期の符号 12本）。

## 多重比較

- 主: 6通りの全期間 adj の |z| 判定（事前の α=5% 両側→|z|≥1.96 相当。Bonferroni なら α=5%/6≈0.83%→|z|≥2.64）。Bonferroni を適用すると通過は TSMOM60\|vol40（|z|=2.83）の 1/6 のみ。
- 補助: raw 6本（同上）、前後半 adj 12本（符号の確認）、半期単位 t 6本（最大 |t|=4.15）、hit_diff の |z|（最大 |z|=3.01、TSMOM60\|vol40）.

## 示唆

- Q159 の未確定を single-symbol と窓3本で再測した。向きは robust（6/6 負）だが、強さは窓依存で、窓を 40・60 日まで長くしたときだけ事前の |z|≥2 を達成する。Q142（TSMOM20・vol20 の群判定）が棄却だったのは、「窓20日では XAUUSD 単銘柄でも弱い」と整合。
- ドリフト除去（μ_bp 固定）は結論を変えない。「高ボラ日に順張りが弱い」は買い持ちドリフトの寄与ではなく、regime-conditional pnl そのもの。
- 「XAUUSD で、過去40〜60日の実現ボラが拡大窓の中央値を上回る日に、翌日の TSMOM60 または DON55/20 の損益が下がる」は、6通り中 3通り（窓40・60）で事前の有意基準を達成。この 3通りに限れば XAUUSD 単銘柄で確定に近いが、6通りすべてでの事前基準には届かず、未確定にとどめる。
