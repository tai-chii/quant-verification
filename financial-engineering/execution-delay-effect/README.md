## 方法（要点）

- 規則 2 本 = TSMOM20、ドンチャン簡略版 55/20（損切りなし）。合図は終値で決まる。
- 約定の遅れ d ∈ {0,1,2,3,5}: 日 t のポジション = s_{t−1−d}。片道コスト段階1込みの日次純損益（bp）。有効日は t ≥ 62（全規則・全 d が定義される日）。
- セル = 銘柄 × 規則（30）。年ごとにセル平均 → 年を単位に平均と t。d − d=1 の対応ありの差も年単位。改善セル数 = 期間内の平均純損益が d=1 より大きいセルの数。最大下落は全期間の累積純損益から。
- 帰無 = 各銘柄の半年の組の中でリターンを並べ替え（B=500）→ 合算の差 (d − d=1) と改善セル数の分布 → z・パーセンタイル。

## 判定（事前固定）

- d=2 と d=3 の両方で、d=1 より改善するセルが過半（≥16/30）かつ合算の年単位 t≥2 → 「合図の直後に逆行がある（短期の反転）」＝新しい条件の穴として記録。
- 改善が帰無の範囲（合算の差が帰無の 95% 点以内）→ 「Korzan の遅れでの改善は運」。
- 片方だけ満たす → 「部分的」（記述）。d=0 が d=1 より t≥2 で良ければ先読みの大きさとして記述（判定に使わない）。
