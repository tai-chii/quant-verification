### 解釈

- **前半（2008〜2016）は強く効いた**: all15 で ρ 平均 0.023・z=3.87、上位1/5の日の逆張り（コスト後）は残り日より 9.1 bp/日 高い（t=3.07）。DellaCorte 2015（15銘柄・ボラ変化が逆張り収益を予測）の原論文の時期と重なる区間で主張を再現。
- **後半（2017〜2026）は消えた**: all15 で ρ 平均は 0 近傍（z=−0.15）、FX8 では **符号が反転**して有意（ρ の z=−1.99、差の t=−2.52、コスト後の水準も −3.16 bp/日）。トレンド系7（金・原油・株指数・BTC）は z=1.90 で境界だが、事前登録の「前後半とも z≥2」を満たさない。
- 公表後効果の典型例: 2015年の発表以降、FX ではシグナルが反転し、トレンド系では残っているように見えるが基準に満たない。知見「公表後の減衰」と整合（Q173 の夜間→日中逆張りも同じ時期に消えた）。
