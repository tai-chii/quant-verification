- 仮説: H: トレンド7（XAUUSD・XAGUSD・WTI・UKOIL・US500・USTECH・BTCUSD）の H4 で TSMOM 60 本（主セル）の純損益 [bp/本] は 0 と区別できない（為替と同じく日中足にはない）。
- 定義: 合図: 60 本前との差の符号（30・120 本は副次）。翌本の終値で約定。片道コストは段階1の表。年×銘柄の純損益 [bp/本]。
- 測るもの: 年単位 t（trend7・全期間・前後半）、粗利の t、IC（Spearman・翌本）。
- 帰無: 合図を循環シフト B=500 → 純損益の帰無分布 → z。
- 多重比較: 判定は主セル 60 本の全期間と前後半（3 本）。30・120 本と IC は記述。
- 捨てた案: 約3: FX8 も同時に（知見済み）、H1 版（Q191 系で済み）、時刻条件つき。
