## 方法（要点）

- セル = 銘柄 × 暦年（2008〜2025、100 日以上）× q ∈ {2, 5, 10, 20}。Lo–MacKinlay の分散比（重なりあり・不偏調整）と不均一分散に頑健な z*。有意 = |z*| ≥ 1.96。
- (a) 4 つの q のうち有意の数が 1〜3 の割合（設定で結論が割れる）。(b) VR−1 の符号が q 間で割れる割合。(c) 同じ銘柄・同じ q で隣り合う年の結論（有意+／有意−／非有意）が変わる割合。
- 帰無 = 日次リターンを年内で並べ替え（真の VR=1）B=300 → (a)(b) の帰無分布・z。
- 群: 全15・FX8・トレンド7。期間: 前半 2008〜2016 ／ 後半 2017〜2025 ／ 全期間。

## 判定（事前固定）

- 全15×全期間で (a) ≥ 2 × 帰無の (a) かつ (a) ≥ 30% → 「結論は設定依存」（Alahmadi の懸念を支持）。
- (a) が帰無と区別できない（z < 2） → 「設定依存は偽陽性の水準」。それ以外は未確定。(c) は記述。
