## 方法（要点）

- 戦略 12 本: TSMOM L∈{5,10,20,40,60,120,250}、ドンチャン簡略版 {20/10, 55/20, 100/50}、MA乖離の逆張り {z>1, z>2}（z=(c−SMA20)/SD20）。各戦略の各日のポジションは 15銘柄のベクトル。片道コスト段階1。共通ウォームアップ 250 日。
- (a) 全履歴の相関 = 戦略の日次損益系列（その日にデータのある銘柄の等ウェイト平均）の Pearson 相関。
- (b) 平均の向き = 時間平均ポジションベクトル。角度 ≥60° のペアで (a) ≤0.5 の割合（選別後）と全 66 組での割合（選別前）。差 = 後 − 前。
- 帰無（登録）= 各戦略の損益系列の循環シフト B 回。退化したときの代替 = 向きのベクトルの戦略ラベルの並べ替え B 回（相関行列は固定。同じ数のペアを無作為に選んだときの差の分布）。
- 期間: 全期間（判定）、前半 2008〜2016、後半 2017〜2026（割合の幅を記述）。

## 判定（事前固定）

- 差（選別後 − 選別前）が帰無の上位 2.5% より外（z≥2）かつ 差 ≥5 ポイント → 「向きの選別は履歴の違いを保証しないが、基準率より改善する」（Nunes と同じ）。
- 差が帰無の区間（2.5〜97.5 点）内、または ≤0 → 「向きだけでは何も言えない」。
- それ以外（z≥2 だが差 <5 ポイント）は未確定。期間で 20 ポイント以上動けば「評価期間依存」を記述。
