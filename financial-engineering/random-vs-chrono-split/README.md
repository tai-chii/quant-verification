## 結果

判定: **H0（両者の楽観に差はない）**

- 設定: 15銘柄 D1_fromH1、L ∈ {5,10,…,300}、4年窓（Y−4..Y−1、本当の翌年 Y）、ランダム分割 75/25・5 回繰り返し（1回目を本採、残り4回は記述）、帰無 B=300（L を無作為化）、SPLIT_YEAR=2017。
- all15_pre（n_years=3, n_cells=30）: O_a 平均 +2.44（t=1.98）、O_b 平均 −0.69（t=−0.30）、**差 O_b−O_a = −3.13（t=−1.69）**、z_diff = −2.68。
- all15_post（n_years=10, n_cells=140）: O_a 平均 −0.55（t=−0.35）、O_b 平均 −1.15（t=−0.92）、**差 O_b−O_a = −0.60（t=−0.53）**、z_diff = −0.92。
- 事前の規則「all15 で前後半とも O_b−O_a > 0 かつ |t|≥2 → H1 支持／|t|<2 → H0」に当て、|差の t| が前後半とも 2 未満のため H0。
- **解釈: 符号は仮説と逆（ランダム分割の方が時系列分割より楽観が小さい）だが、有意ではない。**15銘柄・4年窓・候補 L の格子では、Roelofs 2019-2 の「独立でない分け方は楽観を膨らませる」が検出閾値を超えて現れない。O_b 自体の z は all15 全期間 −1.64・fx8 全期間 −2.18 と負で、L を無作為化した帰無でもランダム分割のテスト成績は本当の翌年に対して低めに出る傾向があり、「漏れだけで楽観が自動で出る」構図は見えない。
