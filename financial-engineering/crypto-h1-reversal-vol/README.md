判定: **支持**（事前登録の4条件を前後半とも満たす: 前後半で rho_mean>0 かつ rho_z≥2 かつ top_minus_rest>0 かつ t≥2）。

**解釈: ボラは1時間逆張りの粗利を予測する（Farag 2024-1 の H1 版）。ただし後半で係数が3〜4倍小さくなり、保守的な往復コスト（5〜30bp）後は売買に使えない。** 粗利の予測は残っても、公表後の弱まりとコストで利益化はできない。Farag の 5分足での結果とは頻度が違うので「売買に使える」とは言わない。
