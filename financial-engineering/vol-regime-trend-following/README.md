## 方法（要点）

- 局面: 日次対数リターンの 20 日標準偏差 v_t が、その銘柄の v の拡大窓の中央値（t を含まない・60 個以上）より上なら「高」、下なら「安定」。翌日 t+1 の損益に対応する局面は L_t（先読みなし）。
- 規則: TSMOM20（20日リターンの符号で翌日を持つ）1本。片道コスト段階1（`COST_RT`/2）。的中 = pos×ret>0（pos=0・ret=0 の日は除く）。
- 差 = 高 − 安定（群の全日をプール）。t は半年を単位（各半年でプールした差の平均／SE）。帰無は各銘柄の局面ラベルを月ブロック単位で並べ替え（損益固定）B 回、z = (差 − 帰無平均)/帰無 SD。
- 期間: 前半 2008〜2016 ／ 後半 2017〜2026。群: 全15・FX8・トレンド7。

## 判定（事前固定）

- 「局面で変わる」 = 全15合算の純損益の差が前後半で同符号 かつ 両期間で |t|≥2（半年単位）かつ |z|≥2。
- どちらかで逆符号、または |t|<2／|z|<2 → 棄却（論文と同じ非有意）。
- 支持でも FX8 は「負けの大きさが局面で変わる」としか言えない（実行者が記述）。
