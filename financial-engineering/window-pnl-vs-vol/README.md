## 結果

- データ: 15銘柄 D1_fromH1（missing=0）。窓数 3122 セル（all）・1360（pre, year<2017）・1762（post, year≥2017）。B=300。
- プールの R²:
  - all: σ+|μ| **0.4112** ／ σ 0.0280 ／ |μ| 0.3141 ／ trend 0.2096。帰無 R² 0.3942・z=**0.4305**。
  - pre: σ+|μ| 0.3390 ／ 帰無 0.3743・z=−0.9211。
  - post: σ+|μ| 0.4363 ／ 帰無 0.4037・z=0.6434。
- 銘柄ごとの Spearman（15銘柄の平均・銘柄単位 t）:
  - σ: ρ̄=0.016・t=0.57（≈0）
  - |μ|: ρ̄=0.4857・t=25.43
  - trend: ρ̄=0.5089・t=30.59

判定: **未確定**（事前固定の規則「R²≥0.3 かつ z≥2 → H1 支持」のうち R² 条件は満たすが z<2 で片方しか満たさず）。

**解釈: Rashid の「ボラに左右される」は向きが違う。** σ はほぼ無関係（ρ̄≈0.02）で、支配するのは窓の |ドリフト| と trend 強度。ただし窓内並べ替え（σ と μ は保ち合図だけ壊す）帰無でも R² が同じ水準（0.39）に出るため、窓損益の |ドリフト| による説明は腕と局面の運を分けるものではなく機械的な帰結（規模の反映）。Q144（2か月窓はランダム売買の上位5%に入る割合 0.8%）と整合。
