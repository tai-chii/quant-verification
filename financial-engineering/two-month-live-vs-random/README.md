## 方法（要点）

- 規則: TSMOM20（20日リターンの符号で翌日を持つ）1本。片道コスト段階1（`COST_RT`/2）。
- 窓: 全銘柄の日付の和集合の上で W=42 日・STEP=21 日（副: 126/63、252/126）。各銘柄は窓内の自分の日（W/2 日以上）。窓の成績 = 日次純損益の合計 [bp]。
- 帰無 = 同じ持ち替え回数 K（|Δpos|>0 の日数）で、窓内の相異なる K 日を一様に選んで符号を反転する ±1 戦略 B 本。コストは反転日に |Δpos|=2 × 片道。パーセンタイル p = ランダム B 本のうち規則より低い割合。
- (a) = p≥0.95 の（銘柄, 窓）の割合。(b) = 銘柄順位（窓の純損益 bp/日）の Spearman の平均（銘柄 8 以上の窓対）。判定は重なりのない窓対 (w, w+2)、登録どおりの連続する窓対 (w, w+1) は記述。
- 期間: 前半 = 窓の開始が 2017 年より前／後半 = 以降（記述）。群: 全15・FX8・トレンド7（記述）。
