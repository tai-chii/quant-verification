## 方法（要点）

- 組 = 銘柄 × 暦の半年（100日未満は捨てる）。**D** = 日次対数リターンの同符号の連の平均の長さ（独立なら 2）。**P** = 20日リターンの符号で翌日を持つ時系列モメンタム1本の、片道コスト込みの日次純損益の平均（bp/日）。コストは段階1の保守値（`kensho_donchian_regime.py` と同じ往復 COST の半分を片道に）。
- 帰無 = 各組の中で日次リターンを並べ替え（自己相関0・ドリフトとボラは同じ）、同じ量を B 回。
- H1（説明）: プールした Spearman(D, P) と帰無の z、半年ごとの横断面 Spearman の平均と t（FM 型）。
- H2（予測）: Spearman(D_前半年, P_当半年) と帰無の z、「前半年の D がその銘柄のそれまでの中央値より上のときだけ順張り」の純損益 − 無条件（半年単位の t）。
- 期間: 前半 2008〜2016 ／ 後半 2017〜2026。群: 全15・FX8・トレンド7。

## 判定（事前固定）

- H1 支持 = 前後半とも ρ>0 かつ z≥2。
- H2 支持 = 前後半とも 予測の z≥2 かつ 条件つき−無条件 >0 で t≥2。
- H1 支持・H2 棄却 = 「説明にはなるが予測には使えない」。
