## 方法（要点）

- r_t = 15分対数リターン。ペア (r_t, r_{t−1}) は直前の足がちょうど 15 分前のときだけ（週末・欠損をまたがない）。
- ρ₁(h) = h（UTC の時）に始まる足での corr(r_t, r_{t−1})。t は標準化した積の平均に Newey–West（Bartlett、ラグ 4 = 1 時間）。
- 期間 = 2021–23 / 2024–26。Holm = 2 通貨 × 24 時 × 2 期間 = 96 本を 1 族（α=0.05）。
- 売買 = 有意な時刻 h で pos = sign(ρ₁(h)) × sign(r_{t−1})、1 本保有。片道 1 pip（USDJPY 0.01、EURUSD 0.0001）を |Δpos| ごとに引く。
- 帰無 = UTC 日の中で足の順序を並べ替え（時刻ラベルと日ごとのリターン集合は保つ）、同じ 96 本の族で Holm を B=300 回 → 有意数・max|t| の分布。

## 判定（事前固定）

- Holm 補正後に有意な時刻が両期間で同じ符号で残れば「時刻依存の自己相関あり」。
- 残っても片道 1 pip 後に（どちらかの期間で）負なら「売買には使えない」。
- 有意な時刻が 0 なら棄却（H1 の結果と整合）。通貨ごとに付け、総合は 2 通貨を並記。

## 結果（2026-10-09、B=300、`results/Q153_result_20261009_104314.json`）

判定: **棄却**（USDJPY・EURUSD とも、Holm 後に両期間で同符号に残る時刻 0）

**解釈: 確定（棄却）。** 時刻で符号が変わる1次自己相関は、96本を1族で補正すると残らない。

- 多重比較: 2通貨×24時×2期間＝96本を1族で Holm（α=0.05）。
- Holm 後の有意: USDJPY 0／0、EURUSD 1（2021–23 の 21時 UTC、ρ −0.127・t −3.68・p_holm 0.022）／0。後期の 21時は −0.058（有意でない）。
- 売買（標本内の参考）: EURUSD 2021–23 の 21時で逆張り → 片道1pip後 −2,530bp（−1.06bp/本）。両期間集合は空なので判定用の売買はなし。
- 帰無: 1本以上有意 0.01、max|t| 97.5% 点 3.35、観測 max|t| 3.68（帰無の 99.3% 点）。1時刻あたりのペア数 2,053〜2,654、NaN なし。
- 全時刻の平均 ρ: EURUSD −0.037／−0.020、USDJPY −0.011／−0.004（弱い一様な負。1pip に比べて桁違いに小さい）。
- 注意: 21時（ロールオーバー）の負は BID だけのデータでのスプレッドの跳ね返りの可能性。試走（`--B 30`、`*_104253*`）の結果も results に残る（判定には B=300 を使用）。
