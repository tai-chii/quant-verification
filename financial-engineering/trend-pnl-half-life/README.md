## 方法（要点）

- 規則2本固定: TSMOM20、ドンチャン簡略版 55/20（損切りなし）。片道コスト段階1（`COST_RT`/2）。
- 年次純損益 y_t = 暦年の日次純損益の平均（bp/日。100 日未満の年は捨てる）。t = 年 − 最初の年。
- (i) y=c（k=1）、(ii) y=a·exp(−λt)+b（k=3。λ をグリッド [−0.5, 3] 刻み 0.005 で探索し a,b は線形 LS）。AIC = n·ln(RSS/n)+2k。ΔAIC = AIC(i) − AIC(ii)。
- λ の区間 = 年のペアを復元抽出するブートストラップ B 回の 2.5／97.5 点。帰無 = 年の順序の並べ替え B 回の λ の 95 点。
- 群: FX8・トレンド7。群ごとに λ の平均・中央値、条件を満たす銘柄数。

## 判定（事前固定）

- 「減衰している」 = 群の過半の銘柄で λ の区間が 0 を含まず（下限>0）かつ 観測 λ が帰無の 95 点より上。
- 「最初から0（減衰ではない）」 = FX8 で ΔAIC<2（一定モデルが指数に負けない）の銘柄が過半。トレンド7 では「一定（減衰ではない）」。
- それ以外は未確定（Q063 と同じ）。
