### 解釈

- **主仮説（USTECH → BTC の H1 先行）は棄却。** 前後半とも z<2 で、符号も反転（前 +0.003 → 後 -0.013）。年ごとの IC がゼロと区別できない。
- **強い同時刻相関（0.33）は確認。** IMF 2022 GFSN の 2020 年以降の相関上昇と整合（ただし日次ではなく H1 の共通時刻）。現物時間（UTC 14–20 時）内でわずかに負、外でわずかに正（どちらも |IC|<0.03）。
- **逆方向（BTC → USTECH）は正で有意（全体 t=5.23・後半 t=6.92）**: ただし年平均は +0.017 と小さく、売買のための大きさではない（粗利 0.4bp/時でコスト 30bp に遠く届かない）。これは Hou・Moskowitz 2005 の型（大きい→遅く反映される小さい）と**逆の方向**で、BTC が24時間取引で情報を先に織り込む側であることと整合する（知見 Q183「暗号資産 H1 逆張り」ともつながる可能性）。
- 多重比較: 判定は前後半の IC_z の 2 本。同時刻・逆方向・時間帯・売買は記述。
