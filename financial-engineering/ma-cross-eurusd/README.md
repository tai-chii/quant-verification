# MAクロス 全パターン検証（EURUSD 4時間足）

## 実行
Mac（ターミナル）:
```bash
cd ~/ワークスペース/作業層/市場/ma_cross_eurusd && ./run_all.sh
```
Windows（win1・win2）: `作業層/夜間/task.bat` を実行（夜間キューに分担ジョブが入っている）

- 3台が別々の位置から計算を始め、Syncthing で届いた他PCの分は飛ばす（速いPCが多く進む）
- 全部そろうと Mac で集計し、report.html が開く。足りなければ少し待って `./run_all.sh` をもう一度
- データは既存の `vault/40_市場/FX/システムトレード/data_EURUSD_H4_dukascopy.csv`（週末の0出来高足は除外）
- Mac のフタは開けたまま

## 何をしているか
| 項目 | 内容 |
|---|---|
| データ | Dukascopy EURUSD H4 Bid、2008年〜2026年6月 |
| MA | SMA と EMA。期間 5〜500本を2刻み（248種）→ 2本 30,628通り＋3本 2,511,496通り、×2種で約508万通り |
| 2本 | 短>長でロング、短<長でショート（ドテン） |
| 3本 | 短>中>長でロング→短<中で決済／短<中<長でショート→短>中で決済 |
| 約定・コスト | シグナル足の終値、往復 0.8 pips |
| 前半/後半 | 期間の中点で分割し、それぞれの成績と順位相関 |
| ランダム化検定 | 収益系列を1000通り循環シフト（売買パターンはそのまま、相場とのタイミングだけ崩す）。個別p値と「全組合せ中の最良」のp値（データスヌーピング補正） |
| ドリフト除去 | 各期間の平均騰落を引いた「タイミングだけ」のシャープ（*_dm） |

## 出力
`results/step*_.../`
- `report.html` … 図表つきレポート
- `summary.json` … 要約（これをClaudeに渡せば解釈と次の検証設計ができます）
- `results.parquet` または `results.csv.gz` … 全組合せの成績

## 拡張（次の段階）
- 時間足: `fetch_data.sh` の `-t h4` を `h1` / `d1` などに。`bt.py` の `BPY`（年あたり本数）も合わせて変更
- 銘柄: `-i eurusd` を `usdjpy` などに。円ペアは `PIP = 1e-2`
- 手動実行: `python3 bt.py --data data/eurusd_h4.csv --step 5 --max-period 200 --kinds SMA`
