## 結果

判定: **未確定（機械判定）／解釈: 規則の型による**

- XAUUSD D1 bid vs ask の不一致率: SMA200 **0.08%**、TSMOM20 **0.06%**、DONCH55_20 **2.58%**
- 事前固定: 3 規則すべて不一致率 <1% かつ年差 |t|<2 → 支持（H1 頑健）。いずれか ≥5% → 対立。間は未確定。
- 2/3 規則（トレンド型）は H1 を支持する水準、ドンチャン（ブレイクアウト型）だけが 1〜5% の未確定ゾーン。
- 純損益の年差 |t| は 3 規則とも 2 未満（最大 1.76、方向はすべて負）。
- スプレッド中央値 2.7bp（D1）／2.2bp（H1）。
- 1 日ずらした自分との不一致: SMA200 2.26%・TSMOM20 9.52%・**DONCH55_20 2.06%**。DONCH の bid vs ask の不一致（2.58%）は1日ずらした自分（2.06%）と同程度。
- H1 でも順位は同じ（SMA200 0.13%・TSMOM20 0.45%・DONCH55_20 1.70%・|t|<2）。

**解釈（結果を見た後の後知恵と明記）**: 連続量と連続量を比べるトレンド規則（SMA200・TSMOM20）では bid/ask の違いはほぼ無視できる。高安の更新で判定するブレイクアウト規則では約 2.58% の日で合図が変わり、1日ずらした自分と区別できないほど不安定。合図の定義に価格の種類を書くべきは**ブレイクアウト規則だけ**。

### 擬似ずらしの設計上の不変（記述）

15銘柄 D1_fromH1 で ask' = bid + COST_RT/2（OHLC に定数を一律加算）で作った擬似 ask との不一致率は、全銘柄・全規則で 0.0。これは **SMA200（close − SMA(close)）・TSMOM20（close[t] − close[t−L]）・DONCH55_20（close vs rolling max/min(high, low) の差）がどれも OHLC への定数加算に対して不変**だから。擬似ずらしで bid/ask の違いを近似する方法は、少なくとも今回の 3 規則では情報を持たない。XAUUSD の実測 bid/ask だけが情報を提供した。擬似ずらしの再設計は、方向性のある加算（open のみ bid・close のみ ask のクロスなど）が必要。
