- **+4h の差は前後半で符号が逆（pre −0.27 → post +10.55）**。n=51 と小さいので外挿不可。全体判定（事前登録）は棄却のままで、副次の記述に留める。

### 解釈

- NFP 発表足で**反応の大きさは確かに拡大**（対照の 3.45 倍）するが、**その後の 1〜4h の方向は、同じ時刻の他の金曜と区別できない**。Andersen ほか 2003 の「指標後の反応は数分で終わる」主張と整合（n=100 事象で +1h・+4h の t と z がどちらも |2| を下回る）。
- 2024 年以降の +4h だけ対照より +10.55 bp 大きいが、2 通貨 51 事象・t=+0.66 で統計的裏付けなし。これを狙う戦略は過剰適合の典型。
- 知見 Q153（15 分足の時刻の自己相関は多重比較で残らない）・Q057（ロンドン開始 30 分の合図は 2025 年以降消えた）と同じく、「時刻イベントで方向性を取る」案は現代の FX ではコスト前でも成立しない例が重なる。
