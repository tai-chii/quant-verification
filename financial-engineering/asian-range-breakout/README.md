### 解釈

- **粗利が全期間ほぼゼロ（−0.09 bp/日）**で、ふるい分けの段階で優位性がない。コスト後に明確に負に出るが、その前にすでに「ブレイクの向きは続かない」。
- 後半だけ粗利 +0.42 bp（z=+1.42）で向きは正になるが、事前固定の z≥2 を通らない。段階2（コストの詰め）に進める価値はない。
- 向き別・レンジ幅別のいずれも負で、符号は安定して「続かない」側。
- 知見 Q057（ロンドン開始30分は2025年以降コスト後に消える）と向きが揃う。実務の定番「アジアレンジ・ブレイク」と、Ranaldo 2009・Breedon・Ranaldo 2013 の時間帯パターンから導かれる「ブレイクの向きは続く」は、FX8 の H1 日足レベルでは支持されない。
