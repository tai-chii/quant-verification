## 方法（要点）

- 仮説: H: 11 通貨の UTC 日足（H1 から）で TSMOM 60 日（主セル）の純損益 [bp/日] は 2018–2021 では正だが 2022 以降は 0 と区別できない。
- 定義: 合図: 60 日（20・120 は副次）。pnl_bp（相対コスト）。前半 〜2021／後半 2022–（暗号資産は分割年 2022）。
- 測るもの: 年×通貨の純損益の年単位 t（前後半・全期間）、粗利の t、11 通貨の等加重束のシャープ。
- 帰無: 合図を循環シフト B=500 → z（前後半それぞれ）。
- 多重比較: 判定は主セル 60 日の前後半 2 本。20・120 日・束のシャープは記述。
- 捨てた案: 約3: 横断（Q263 に分離）、H4 版、コストを 10bp にする（保守値に統一）。
- 先行研究チェック: WebSearch 2026-10-10「cryptocurrency time series momentum daily after 2022 decline transaction costs altcoins empirical」: AUT の TS/CS モメンタム論文、open.icm.edu.pl「Cryptocurrency Factor Momentum」、Reading の BTC 日中 TSMOM。 11 通貨の日足・2022 分割・循環シフト帰無・相対コストで前後半の判定は未確認（条件の穴・公表後）。
