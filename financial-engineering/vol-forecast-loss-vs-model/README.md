## 結果

判定: **棄却（H0 支持: 為替では損失関数の差はモデルの差より小さい・Tokajuk の構図は為替で再現しない）**

- 前後半: 前半（〜2016）R̄ = 0.603、後半（2017〜）R̄ = 0.5661（両方とも <1、符号・大きさとも整合＝分割一致）
- 水準合わせの効果 D_loss_reduction = 97.75%（Tokajuk 2026-2 の 77% と同じ向きだが大きさは強く出た。目的変数が二乗リターンで裾が重く、水準が支配するため）
- Tokajuk 2026-1 の中央値 2.91（暗号資産・Garman-Klass 分散）とは逆向き。為替の日次二乗リターンでは、学習損失の選択より族（EWMA/移動窓/HAR）の選択の方が大きく出る。
- `by_eval` の値は非零（例: EURUSD MSE で D_loss=0.0133・D_model=0.0264）＝各族で3つの学習損失が同じハイパーパラメータに潰れていない。README 試走で心配した退化は起きていない。

## 解釈のまとめ

- Tokajuk の「損失関数 ≫ モデル」の構図は、暗号資産×Garman-Klass 分散に強く効く設定依存の可能性が高い（為替・二乗リターンでは逆の構図）。
- ただし水準合わせの効果（D_loss を 50% 以上減らす）は為替でも強く成立（77% 対 97.75% と大きさは異なるが方向は一致）＝「生の損失関数間差の多くは水準で説明できる」という Tokajuk 2026-2 の主張は為替でも支持される。
- 為替のボラ予測では、損失関数を凝るより族（EWMA の λ・移動窓の n・HAR の係数）を工夫する方が成績の幅に効く。
