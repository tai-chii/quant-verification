## 方法（要点）

- 年 t（2008〜2025）の VR(q=5) と頑健 z*。「予測できる」= |z*| ≥ 1.96。符号: VR > 1 → 順張り、VR < 1 → 逆張り。
- 年 t+1 の規則 1 本: TSMOM5（sign(c_t − c_{t−5})、翌日約定）。VR の符号で向きを決める。片道コスト段階1（`COST_RT` の半分）。予測できない組にも同じ規則を当てる。
- (a) 予測できる組のうち翌年の純損益 > 0 の割合。(b) 年ごとに銘柄平均 → 年単位の平均と t。(c) 予測できる組 − 予測できない組（セルをプール）。
- 帰無 = 年 t のラベルを期間内のセルで並べ替え B=500 → (c) の z（(a)(b) の帰無も参考に出す）。
- 期間: 年 t+1 で 前半 < 2017 ／ 後半 ≥ 2017 ／ 全期間。

## 判定（事前固定）

- 期間ごとに (a) ≥ 60% かつ (b) t ≥ 2 かつ (c) 差 > 0 で z ≥ 2 → 「予測可能性は翌年の利益に変換される」。(b) t < 2 → 「変換されない」（Alahmadi の整理を支持）。
- 前半・後半とも「変換される」→ 支持。両方「変換されない」→ 棄却。割れたら未確定。
