## 結果

判定: **棄却**（事前の判定規則「前後半のどちらかでコスト後 t<2 → 棄却」に当てはまる。実際は両方とも t<2 で、後半は負方向に有意）

- 結果 JSON: `results/Q173_result_20261009_225354.json`
- 合算（8通貨を日ごとに平均・コスト後 bp/日）
  - all（2015–2026、n=4199日）: A_net_mean = −0.79、t = **−2.45**、null z = +2.57（並べ替えより悪くはない方向の 2.6σ だが、水準そのものが負）
  - pre（2015–2020、n=2192日）: A_net_mean = −0.44、t = **−0.96**、null z = +3.04 → 0 と区別できない
  - post（2021–2026、n=2007日）: A_net_mean = −1.17、t = **−2.61**、null z = +0.33 → 後半は負方向に有意
  - 通貨別で A_net_mean がプラスなのは GBPUSD（+0.11, t=0.18）と GBPJPY（+0.29, t=0.42）の2通貨のみ。どちらも t<1
- A（夜間→日中の逆）÷B（従来の短期リバーサル・前日の日中の逆）: 全期間 ratio=0.55、粗利の A_gross_mean は +0.56 bp/日（t=1.73）で、往復コスト（段階1）を引くと負に転じる。DellaCorte の「約5倍」は再現しない
- 粗利では8通貨中7通貨で A_gross_mean>0 だが、往復コスト（1日1往復）が bp 平均を上回って全銘柄で負へ押し下げる

### 解釈

- 粗利は8中7通貨でプラスなので、「夜間と日中の負の繋がり」そのものはわずかに残っている可能性がある（null z は all/pre とも+2σ 以上）。ただし、段階1の往復コスト（EURUSD 等で 2 pips、JPY クロスで 2 pips、合わせて 2 bp 前後）を超える水準ではない
- 2021年以降は粗利の中央値も薄まり、合算は負方向にずれる（USDJPY・AUDUSD・EURJPY が後半に悪化）。知見「為替の超短期の平均回帰は2015年以降の1時間足では消えた」の延長で、「夜間と日中の繋がり」も実務コストに対して薄い
- DellaCorte らの通貨先物（1982–2014、CME）での 0.04%/日（4bp）は、2015年以降のスポットでは消えている。頻度（日次の毎日往復）とコスト（CME の限月乗り換えと現物スプレッドの差）の違いもあるが、本検証の範囲ではコスト後に残らない
- 連鎖の矛盾なし。むしろ知見と整合（夜間→日中の逆もコスト後に残らない）
