## 方法（要点）

- 規則 = TSMOM20（翌日約定・片道コスト段階1）。銘柄のシャープ = 日次純損益（bp）の 平均/SD × √252。等ウェイト = 選んだ銘柄の日次純損益（bp）の単純平均（15 銘柄の日付の和集合で揃え、無い日は除く）。
- 選択期間 2008〜2016 でシャープ上位 k ∈ {3, 5, 8} を選ぶ。(a) 選択期間の k 銘柄の等ウェイト・シャープ、(b) 後半 2017〜2026 の同じ k 銘柄、(c) 後半の全 15。膨らみ = (a)−(b)、選択の効果 = (b)−(c)。
- 年単位の t: 年ごとの等ウェイト・シャープで、(b)−(c) は後半の年の対応ありの差、(a)−(b) は選択期間の年 vs 後半の年の Welch。
- 帰無 = 選択期間の銘柄の成績を並べ替え（後半で見る k 銘柄が無作為になる）B=500 → (a)−(b) と (b)−(c) の 95% 点と z。Bailey の期待最大シャープ（N=15、横断面の平均・SD）を併記。

## 判定（事前固定）

- (b)−(c) が年単位 |t| < 2 → 「事後の銘柄選択は後半で残らない」＝選択バイアス。
- (a)−(b) が帰無の 95% 点以内 → 「膨らみは運の範囲」。
- (b)−(c) が t ≥ 2 → 「銘柄の持続的な差がある」（未確定・条件の穴として記録）。
