## 示唆（判定とは別の記述）

- 標準手順への反映は保留。方向と単調性は強いが、第一指標が有意に届かず、「規則に e≥L を足す根拠」とまでは言えない。基盤の「出口で検証する決まり」に、ふだん使う CV は **e=0 を使わず e=L でそろえる**を推奨として書く（硬いルールにしない）。
- 短い L（≤50）＋ e=0 は特に楽観の疑いが強い（diff が −2〜−4 bp/日の群）。短い L を使う検証（kaggle 版の embargo の偽陽性と同系統）では e≥L を強く推奨。
- 本検証は年単位（14 年）での主張をするには力が足りない。別の切り方（通貨別・ランダムスプリット・ブロック・block-length の sensitivity）で確証を得るのが次段階。

## 方法（要点）

- 候補 = TSMOM の参照日数 L ∈ {5,…,300}（60）。片道コスト段階1込みの日次純損益。
- ローリングオリジン = テスト期間は暦年 Y（固定）。選択期間はテスト開始の e 営業日前で終わる直前の 756 営業日（3 年）。e ∈ {0,1,5,10,20,60}。選択は選択期間の平均純損益が最大の L。
- テストの量 = テスト年の平均純損益（bp/日）と最大下落（bp）。年ごとに銘柄平均 → 年を単位に平均と t。e − e=0 の対応ありの差も年単位。
- 単調性 = e 6 点と平均純損益の Spearman。L 別 = e=0 の L を {≤50, 51〜150, >150} に分けて差 (e=20 − e=0)。
- 帰無 = L をランダムに選ぶ（B=300）→ 年単位集計の純損益の分布 → 各 e の z。

## 判定（事前固定）

- e=0 と e=20 のテスト純損益の差の |t|<2 かつ 単調でない（|Spearman|<0.8）→ 「エンバーゴは結論を変えない（この規則では）」。
- 単調（|Spearman|≥0.8）で |t|≥2 かつ e=20 − e=0 < 0（e=0 が良い）→ 「e=0 は楽観」＝基盤の決まりに e≥L を追加する根拠。
- 単調で |t|≥2 だが e=20 の方が良い → 「e=0 は悲観（想定外）」、片方だけ → 「どちらにも当てはまらない」（記述）。
