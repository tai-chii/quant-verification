### 解釈

- **「ダマシを減らす」が k=3 では成立しない**: 取引回数は 247→288 と逆に増え、短保有率も 49%→52% と減らない。確認の出口規則（反対符号で建玉 0）が確認待ちと衝突して短い建玉を増やしている。
- **前後半で符号が逆**: pre 差 +0.15 bp/日・post −0.40 bp/日 で、どちらも事前固定の閾値（±2）に届かず **未確定**。post は t=−1.86 と負に寄り Q156（遅れは損）・Zakamulin 2014 の方向と揃うが、pre は逆方向。
- **確認は単純な遅れよりは良い**: conf3 − lag3 = +0.44 bp/日（trend7 だけで +0.97）。確認は「遅れそのもの」ではなく、「遅れつつダマシを少し除く」効果が trend7 で見える。ただし基準（毎日の符号）には届かない。
