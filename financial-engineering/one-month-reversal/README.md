### 解釈

- **コストの話ではない**: 粗利でも −1.18 bp/日 で負。信号そのものが系統的に逆向き。
- **負 t と z≈0 の組み合わせの意味**: 「上昇ドリフトを持つ資産を 1 か月規則で短く取る」の構造的な負のドリフトを、循環シフトも同じく拾うため、負 t が帰無分布の中に収まる（z は 0 近傍）。t が負でも z<2 なら「反転の情報」ではなく「ドリフトを逆に取っているだけ」で、売買には使えない（売買の符号判定は t ではなく z の裏付けが要る）。
- **12-1 モメンタム対照は時系列では弱い正**（all15 all mom121_bp=+0.38 t=0.53）: Jegadeesh・Titman 1993 の横断の強さは本検証の時系列・銘柄プールには出ない。横断と時系列は別物（Q214 と同じ結論）。
- **副次: fx8 後半だけ局所的に正**（rev_bp=+0.84 z=+2.58）: 為替の 2017 以降に限り短期反転が弱く残る可能性を示す。ただし all15 前後半の判定には寄与しない。trend7 は全期間 z<−1.5 で逆に強い継続寄り（商品・株指数・BTC では 1 か月反転の仮説は符号ごと間違い）。
