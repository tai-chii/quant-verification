## 方法（要点）

- 規則 2 本固定: TSMOM20、ドンチャン簡略版 55/20（損切りなし）。終値で判定・翌日から保有。
- 純損益(m) = mean(粗損益) − m × mean(回転コスト)、m ∈ {0, 0.5, 1, 1.5, 2, 3, 5}。損益分岐 m* = mean(粗)/mean(回転)（線形なので補間＝厳密）。「m* × 実測」= m* × 片道コストの bp 平均。
- XAUUSD の UTC 日足は H1 bid から作る（6 本未満の日は除く）。片道コスト = 約定時間帯（最後の H1 足の時の最頻値）のスプレッド中央値。
- 帰無 = 暦年の中で日次対数リターンを並べ替えた価格列で同じ規則 → m* の分布 B=300（粗利が運のとき m* がどれだけ出るか）。

## 判定（事前固定）

- XAUUSD・実測コスト・全期間・規則ごとに: m* ≥ 2 かつ 帰無の上位 5% より外（パーセンタイル ≥ 0.95）→「実用の余地あり」。m* < 1 →「実測コストで消える」。間は未確定。
- 15銘柄の m* の表は記述。
