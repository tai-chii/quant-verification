## 結果

判定: **棄却（前後半のどちらかで |t|<2）**。
解釈: **週足の順張りは日足より強いという証拠は得られなかった。IC の差はむしろ有意に負（弱く情報としても劣る）。**

- 事前固定の判定: 前後半ともに |t|<2（0.50 と −0.57）。純損益の差の z も 2 未満。**棄却**。
- 符号も揃っていない（前半 +、後半 −）。
- IC の差は全期間・後半で有意に負（t=−4.66・−5.46）。情報自体も週足の方が弱い（コスト以前の話）。
- FX8 の pnl 自体、後半は日足・週足とも負（Q019「先進国通貨の日足テクニカルは2016年以降0本」と整合）。
