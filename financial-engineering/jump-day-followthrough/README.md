## 方法（要点）

- 仮説: H: 日次リターンが |ret|>2.5·σ60 のジャンプ日の翌日の y1 = sign(ret)·ret_{t+1} [bp] と翌 5 日の y5 は 0 と区別できない（継続も反転もしない）。
- 定義: σ60 は t−1 までの 60 日標準偏差（先読みなし）。y1・y5（重なりを避け y5 はジャンプ日から 5 日の非重複）。対照: 非ジャンプ日の同じ y。
- 測るもの: 年×銘柄の y1・y5 の年単位 t（all15・群別）、ジャンプ日の数。前後半。
- 帰無: ジャンプ日ラベルを年内で並べ替え（perm_within）B=1000 → y1・y5 の帰無分布 → z（2 本）。
- 多重比較: 判定は all15 の y1・y5 の全期間 2 本。前後半・群別は記述。
- 捨てた案: 約3: 閾値 2σ・3σ（2.5 に固定）、ジャンプの向き別（買い/売りの非対称）、H1 のジャンプ。
- 先行研究チェック: WebSearch 2026-10-10「large daily price jump continuation or reversal next day futures currencies commodities extreme return days empirical」: Mazouz・Wang（Cardiff ORCA）、Inderscience 2015（商品先物の大きな一日の変化）、Montclair（通貨先物の日中反転）。 15 銘柄 CFD・2.5σ・翌日と翌 5 日・前後半・年内並べ替え帰無で事前固定の判定は未確認（追試＋条件の穴）。

## 判定（事前固定）

all15 で y1・y5 とも全期間 |z|<2 → 支持（続かない）。y1 または y5 が前後半とも同符号で |z|≥2 かつ |t|≥2 → 棄却（継続か反転かを書く）。それ以外 → 未確定。
