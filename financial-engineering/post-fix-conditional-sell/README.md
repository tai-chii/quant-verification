## 結果

判定: **棄却**（Bessho-2 の条件つき主張は 2×2 の構造では再現しない）

**解釈:** 「五十日×上昇」セル単体のコスト後平均は 2008-2016 で 4.14bp (NW-t=2.49) と 0 から離れており、Bessho の主張の方向は正しい。ただし、他 3 セルとの差（D）の月内並べ替え帰無分布が広く、「このセルだけに効く」までは言えない（z=1.51）。期間別に大きく動く（2008-2016: z=1.51 → 2017-2022: z=2.33 → 2023-2026: z=0.99）のも「条件つきで安定して効く」から遠い。アイデア候補の次の一手: (a) 上昇の閾値を bp で刻む（捨てた案）、(b) 日中の執行コストを変える、は追加標本の消費になるので優先度低。
