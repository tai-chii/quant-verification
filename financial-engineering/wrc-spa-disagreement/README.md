## 方法（要点）

- ルール群 = TSMOM の参照日数 L ∈ {5,…,300}（60）× {買いのみ・売りのみ・両方} = 180 本。基準 = 0（現金）。日次純損益は片道コスト段階1込み。各期間は t>300 の日だけ。
- セル = 銘柄 × 前半(<2017)/後半(≥2017) = 30。各セルで循環ブロック・ブートストラップ（長さ 5、B=999、同じ乱数を 3 検定で共有）。
- WRC = max_k √n d̄_k と max_k √n (d̄*−d̄) の分布。SPA = スチューデント化（ω̂ はブートストラップ SD）。consistent = はっきり悪いルール（√n d̄/ω̂ ≤ −√(2 log log n)）だけ中心化しない。conservative = 全ルールを 0 に中心化（p が最大）。
- (b) サイズ = 期間内でリターンを並べ替えた価格でルール群を作り、並べ替え帰無の期待純損益 μ0（100 回の平均）を引いて真の差 0 にし、同じ 3 検定を 20 回 × 30 セル。
- (c) 検出力 = (b) のデータの 1 本（L=20・両方）に +1bp/日。

## 判定（事前固定）

- (a) 判定（5%）が割れるセルの割合 ≥ 30% → 「検定の選び方で結論が変わる」＝基盤の決まりに「3つを併記」を追加する根拠。
- (b) 名目 5% を 2 倍以上（≥10%）超える検定があれば「依存で膨らむ」（RCtest 表2 と整合）を記録。
- (c) は記述。

## 結果（2026-10-09、B=999、size-reps=20、`results/Q154_result_20261009_195405.json`）

判定: **棄却**（(a) 割れ 13.8%＜30%、(b) 名目の2倍を超える検定なし）

**解釈: 確定（棄却）。** 3つを併記する決まりは不要。SPA(consistent) を主に、WRC を参考に並べる。

- 多重比較: 観測 29 セル × 3 検定 = 87 本の p（個々を有意と数えず、割れの割合だけを使う）。帰無 580 データ × 3 変種 × 3 検定。
- (a) 割れ 4/29（XAUUSD・US500・USTECH・BTCUSD の後半。いずれも SPA 棄却・WRC 非棄却、境界付近）。SPA の consistent と conservative の差は最大 0.016、順位相関 1.000。WRC–SPA は 0.967。BTCUSD 前半はデータ不足で除外（29 セル）。
- (b) サイズ（中心化あり）: WRC 3.4%・SPA c 3.1%・SPA u 3.1%。帰無で割れる割合 2.1%。中心化なし（raw）は WRC 4.7%・SPA c 6.7%・SPA u 5.9% だが、並べ替えでもドリフトは残るので、買いのみのルールの真の差は負とは限らない（README 冒頭の「コストで真の差が負」は買い持ちの分を見落としている。参考値）。
- (c) 検出力（+1bp/日）: WRC 4.5%・SPA 4.0%＝サイズ並み。陽性対照が弱すぎて検出力の比較はできない。
- 要確認だった Hansen (2005) の中心化は、arch（Python）の SPA 実装の lower／consistent／upper と一致（閾値 −√(ω̂²/n·2 log log n)）。ω̂ はブートストラップ分散（arch の既定は Newey–West 型）。
- RCtest 表1（consistent p<0.001・conservative p=0.469）のような大きな割れは再現しない。
