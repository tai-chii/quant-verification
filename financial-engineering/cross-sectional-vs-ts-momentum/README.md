### 解釈

- 事前固定の判定ルール「前後半とも XS−TS の t ≥ 2 → XS が強い、t ≤ −2 → TS が強い、他は差なし」に照らして、前後半とも XS−TS の t は 2 に届かず（+0.25・+1.25）、「差なし・ノイズ」で確定。
- 2008-2026・15 銘柄・コスト後では **TS は全期間でほぼゼロ**（t=−0.15）。Moskowitz・Ooi・Pedersen 2012 表 5 の TS 優位は、公表後の 2008-2026 では消えている（Goyal・Jegadeesh 2018 の消失指摘と整合）。XS は正の方向だが t=1.53 で有意ではない。
- Goyal・Jegadeesh 2018 の「XS−TS の差の大部分は TS のネット・ロング（タイミング）」仮説（H1）は、本検証では**支持されない方向**。後半で TS'（TS からネット・ロング寄与を除く）は TS より **悪く**（−1.78 vs −1.16bp/日）、ネット・ロングは TS を助けていた。XS−TS' の後半 t=+2.06 は XS−TS の +1.25 より大きく、ネット・ロングを剥がすと XS 優位が広がる。これは「差はタイミング」の形と逆（記述・判定の対象外）。
- **副次観察**: TS の平均ネット・ロングが前半 −0.02（ほぼ中立）→ 後半 +0.25（買い超過）と大きく変わっている。株・コモの上昇期間の長さと、12 か月 TSMOM の設計上の遅さの組み合わせを反映している可能性。
