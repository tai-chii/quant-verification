### Q207 との比較

- 形: Q207 は L=252 単独・値幅調整なし・暦月下位1割（n=18）／Q224 は 1/3/12か月合成・σ60値幅目標・下落局面（n=6）。
- どちらも「平均は 0 と区別できない」で一致（Q207 の diff z=0.07、Q224 の z=−0.70）。
- 違う: Q224 の方が合計 bp は正で局面の 2/3 が勝ち（Q207 は暦月単位で +96 bp・t 0.58 と同程度）。「下落局面」の切り方を Hurst 2017 の形に合わせても、手元の短い期間（6 局面）では "stress alpha" は帰無を超えない。
