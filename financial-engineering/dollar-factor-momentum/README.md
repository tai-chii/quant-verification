- **解釈**: ドル因子は 6 ペアの変動の半分を占めるのに、その順張りは個別ペアの順張りとほぼ同じ向き（79% の日で一致）で、損益も区別できない。後半は A・B とも負で、Q019（個別ペアの日足テクニカルは 2016 年以降 0 本）の「消えた」はノイズを均しても戻らない。ドル因子の順張り単独も前後半とも z<2（前半 1.03・後半 −0.19）。
- 多重比較: 判定は L=60 の前後半の差の t と z の 4 本。L=20・250 と A 単独は記述。L=20 の全期間差 t 1.22 も 2 に届かない。
- **実装上の注意（判定は変わらない）**: 帰無は A の合図だけを循環シフトし B を固定するので、差の z は A 単独の z と数学的に同じ値になる（表の z 列が一つで足りる理由）。「差」の帰無を作るなら A と B を同じシフトで動かすか、年単位のブロックで差を並べ替える必要があった。判定は t 側で棄却が決まっており影響しない。
- 原典との対応: Verdelhan 2018 は**同時点の説明力**（ドル因子とキャリー因子で 2 国間レートの変動の大半を説明）の主張で、順張りの効きは主張していない。原典の表 1 の数値は今回開いていない（手元の R² は上の記述のみ）。本検証は「説明力が高い因子なら時系列の順張りも効くか」という派生の問いで、否定されたのはこの派生。Lustig・Roussanov・Verdelhan 2014 のドル・キャリー（金利差で向きを決める）は試していない。
