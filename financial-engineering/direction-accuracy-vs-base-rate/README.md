判定: **方向の的中率は基準率を超えない（確定）**

**解釈: 確定。** 4本の単純な規則はどれも「多い側を言い続ける」に勝てない。前日の符号は基準率より平均3ポイント低く、HSAT のような「方向の的中率・F1」で成果を示す論文は、少なくともこの基準率（日本株なら Up 45.7% → 下を言い続けて 54.3%）と並べないと評価できない。

## 方法（要点）

- 目的変数 = 翌日の符号 sign(c_{t+1} − c_t)（0 の日は除く）。予測器 4 本固定: (a) 常に上、(b) 前日の符号、(c) TSMOM20 の符号、(d) 200 日線の上下。4 本とも同じ日の集合（t ≥ 200・全予測が非 0）で評価。
- 基準率 = max(p_up, 1 − p_up)（銘柄×期間の同じ日集合）。差 = 的中率 − 基準率。t は的中 0/1 の日次系列の Newey-West（5 ラグ）。片側 p → Holm（120 本）。
- 帰無 = 翌日の符号を銘柄×期間の中で並べ替え（予測の列は固定・基準率だけが残る）B=500。各組の的中率の帰無 z と分位を併記。
- 期間: 前半 2008〜2016 ／ 後半 2017〜2026。全期間は記述。

## 判定（事前固定）

- Holm 補正後に有意（片側 α=0.05）かつ 的中率 − 基準率 ≥ 1 ポイント の（銘柄, 予測器, 期間）が 0 → 「方向の的中率は基準率を超えない」。
- トレンド7 で (c)(d) が超える銘柄が 3 以上 → 「上昇相場の基準率で説明できるか」を p_up との比較で記述。
