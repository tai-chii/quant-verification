## 方法（要点）

- 候補 = TSMOM の参照日数 L ∈ {5,…,300}（60 通り）。J ∈ {1,2,4,8,16,32,60} は先頭から J 個（L=5…5J、固定）。
- 年 t の候補ごとの純損益（bp/日・片道コスト段階1）で最良の L* を選び、楽観 = P_t(L*) − P_{t+1}(L*)。銘柄×年でプール、年を単位に t。
- Alonso の限界の幅 = √(log(J/0.05)/(2n)) × σ（n = 年 t の日数、σ = 年 t の L* の日次純損益 SD）。比 = 限界の平均 ÷ 楽観の平均。
- 帰無 = 各暦年の中で日次対数リターンを並べ替えた価格列から翌年の純損益を出す（選択は実データの年 t のまま）B=300。
- 期間: 前半（選択年 < 2017）／後半（≥ 2017）。

## 判定（事前固定）

- Spearman(J, 楽観の平均) ≥ 0.8（7 点）→「選択の楽観は J で増える」＝支持。
- 比（J ≥ 2 の中央値）≥ 0.9 →「限界は使える」。< 0.7 →「時系列では限界が狭すぎる」（Alonso p28 の注意を実証）。間は未確定。
- 前半と後半で割れたら未確定。
