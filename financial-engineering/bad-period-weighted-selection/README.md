## 方法（要点）

- 候補 = TSMOM の参照日数 L ∈ {5,…,300}（60 通り）。日次純損益は片道コスト段階1込み（bp/日）。
- 選択窓 = テスト年の直前 3 暦年（固定窓）。目的関数 A = 平均、B = 下位 20% の日の平均（CVaR 型）、C = 平均 − 最大下落/日数。各目的関数で最大の L を選ぶ。
- 標本外（テスト年）の最大下落（累積 bp の山からの深さ）・純損益（bp/日）・シャープ（√252 で年率化）。差は対応あり（同じ銘柄×年）。銘柄×年でプール、年を単位に t。
- 帰無 = 各（銘柄, 年）で L を一様ランダムに選ぶ B=300 → 標本外 MDD の平均の分布。
- 期間: 前半（テスト年 < 2017）／後半（≥ 2017）。

## 判定（事前固定）

- 目的関数 X ∈ {B, C} ごと、前半・後半それぞれで: 最大下落の差（A − X）> 0 で 年単位の t ≥ 2 かつ 純損益の差（X − A）の t > −2 →「悪い時期を重くする選択は下落を抑える」。最大下落の差の t < 2 → 棄却。
- 総合: B か C が前後半とも支持なら支持。B・C とも棄却の期間があれば棄却。それ以外は未確定。
