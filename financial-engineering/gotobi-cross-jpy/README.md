- 2008-2016 で有意だったのは USDJPY のみ → **初期はドル固有**。
- 2017-2022 では3通貨とも z≥2.3 → **知られる前後の時期にクロス円へ染み出した**（「クロス円の円売り需要」の読みが可能）。
- 2023- は3通貨とも z<1 → **論文の公表（2023年1月）前後で3通貨とも同時に消えた**。知見「ドル円の五十日の仲値前のドル高は2020年までは再現するが2023年以降は消えた」のクロス円への拡張。
