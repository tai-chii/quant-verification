## 判定
**確定: 押し目・逆張りの D1 系の結論は、データ源を Dukascopy に差し替えても変わらない。** Q137 で付けた「保留扱い」は解除。
今後 D1 の為替を新しく使うときは `D1_fromH1`（Dukascopy・UTC 締め）を使い、Yahoo の為替日足は使わない。
