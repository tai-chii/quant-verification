## 方法（要点）

- 候補 = TSMOM の参照日数 L ∈ {5,…,300}（60 通り、J=60 固定）。s_t = sign(c_t − c_{t−L})、翌日ポジション。
- 日次純損益 [bp] = pos × 翌日リターン × 1e4 − |Δpos| × 片道コスト（COST_RT/2 を bp 換算、段階1 の保守値）。
- 年 t の候補ごとの平均で最良 L* を選び、**Naive_t** = max 平均、**OOS_t** = 翌年 t+1 の L* の平均、**Opt_t = Naive − OOS**。
- **BBC_t**: 年 t の n 日を**ムービングブロック・ブートストラップ**（BLOCK=20）で n 日選んで in-bag とし、残り（out-of-bag、MIN_OOB=20 日以上）で L*_b の平均を測る。B=500 回の平均。**Res_t = BBC − OOS**。
- 集計: (銘柄, 選択年) をプール。全15／FX8／トレンド7、前半 t<2017／後半 t≥2017／全期間。
- 帰無: 翌年 t+1 の日次対数リターンだけを並べ替え（コンテキスト。Opt の存在検定には使わない）。B_NULL=200。

## 判定（事前固定）

前半・後半のそれぞれで:

- 前提: 年単位 t_year(Opt) ≥ 2（楽観が年ごとに安定して正）。満たさなければ H1 判定不能。
- **H1（削減）**: ratio = |mean(Res)| / |mean(Opt)|。≤ 0.3 支持（BBC は楽観を 70% 以上削る）／≥ 0.7 棄却／間は未確定。
- **H2（較正）**: 年単位 |t_year(Res)| < 2 で支持（残留は 0 と区別できない）、≥ 2 で棄却。
- 全体: 前後半で H1・H2 が一致したらその判定、割れたら未確定。
- 多重比較: 期間 3 × 群 3 の集計のうち、判定は **全15 の前半・後半 の H1・H2 のみ**。他は副次。

## 結果（2026-10-09 Opus 実行）

- 本番: `results/Q172_result_20261009_224213.json`（245 セル・B=500, B_NULL=200・22 秒）。
- **Opt**（素朴な選択の楽観）: 前半 +8.05 bp/日（t_y=+4.72）・後半 +10.27 bp/日（t_y=+5.13）→ 年ごとに安定して正。
- **Res**（BBC の残留）: 前半 **−0.93 bp/日**（|t_y|=0.54）・後半 **+0.66 bp/日**（|t_y|=0.36）→ 0 と区別できない。
- **ratio**: 前半 **0.12**・後半 **0.06**（全期間 0.007）→ BBC が楽観の **88–94% を削る**。
- 機械判定: **H1 支持・H2 支持**（前後半で一致）→ **判定: 支持（確定）**。
- Tsamardinos 原典の性質と整合: §6.1「BBC は controversially やや悲観 (conservative) 側に偏る」→ 本検証でも前半 Res は負（−0.93）、原典の分類問題で最大 0.013 pt 差を、順張り（時系列）でもブロック長 20 なら同程度に抑えられた。
- 対立仮説（§7 p28「時系列では独立行の BBC は壊れる」）は**ブロック長 20 で回避された**ことを実データで示した。
