**機械判定**: H1a 支持（前後半とも同符号＋|z|≥2）／H1b 棄却（後半で符号が逆転）。

**人の解釈**: H1a は事前登録の規則では確定だが、効果は前半 35bp から後半 1.5bp へ 23 倍減衰（Caporale・Plastun 2019 の BTC 月曜効果もサンプル後に消えていると整合）。後半の年ごとの t は +0.81 で、年間一貫性は無い。暗号資産の週末ボラは前半 1.87 倍から後半 1.07 倍まで平日と並び、市場の成熟（24/7 取引への機関参入）が進んだと解釈できる。順張り（TSMOM24）の弱さ（H1b）も後半で消滅・反転した。

**用に供する余地**: 無い。後半 1.5bp は往復コスト 30bp の 5% で、取引で取りに行くには小さすぎる。帰無が狭いため z は大きく見えるが、年間一貫性が無い以上、実運用の優位性としては採らない。

**多重比較の扱い**: 判定本数は 4 本（前後半 × H1a/H1b）。Holm で見ると H1a 前半（p ≈ 0）、H1b 前半（p ≈ 0.00001）は補正後も有意。後半の H1a（p ≈ 1e-6）も個別には有意だが、効果量が小さいため実用判断には使わない。
