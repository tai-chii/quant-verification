# mahjong

雀魂の戦術をバックテストで検証するコード。対戦データ・戦績台帳は非公開（Obsidian vault側）のため、このリポジトリにはコードのみを置く。

| ファイル | 役割 |
| :--- | :--- |
| `senseki.py` | 戦績CSVから区間（前回スナップショットからの差分）を標準誤差つきで逆算する。`MAHJONG_DATA_DIR` 環境変数でデータの場所を指定する |
| `bots.py` / `run.py` | mjai + libriichi によるマイルールのバックテスト環境（対人・東南戦） |
| `solo/` | 対人要素を除いた完全ソロ環境での門前牌効率シミュレータ（向聴計算を2実装で相互検証） |

検証結果・方針・対戦データの読み方は非公開のため割愛。方法論の要点だけ書くと: 押し引き・鳴き・リーチ判断の是非は実戦ではなくバックテストで決め、検証は必ず1回に1ルールだけ変えるアブレーションで行う。
