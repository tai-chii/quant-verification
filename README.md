# verification-lab

検証のポートフォリオ。分野を問わず「その仮説は本当に成り立つか」を、再現できるコードと手続きで確かめた記録をまとめています。

## 分野

| ディレクトリ | 分野 | 内容 |
| :--- | :--- | :--- |
| [financial-engineering](./financial-engineering) | 金融工学 | 為替・株のトレード手法・シグナル・アノマリーの検証、ニュース駆動シグナルの自動検証（fundagent） |
| [mahjong](./mahjong) | 麻雀 | 雀魂の戦術を対人バックテストとソロシミュレータでアブレーション検証 |
| [competitions](./competitions) | データサイエンス | Kaggle・Numerai などのコンペ参加実績（モデル学習・アンサンブル・提出パイプライン） |
| [tools](./tools) | 共通 | 検証キューの管理、検証一覧の自動生成など、検証パイプラインを回すための補助ツール |

各分野の詳細は、それぞれのディレクトリの README を参照してください。

## 共通の方針

分野が違っても、検証の進め方は揃えています。

- **帰無仮説と比べる**: ランダム化検定・ブートストラップなどで「偶然でも出る程度か」を必ず確認する。
- **再現性を見る**: 前半/後半の分割、アウトオブサンプル、独立データでの追試で結果が残るかを確かめる。
- **一度に一つだけ変える**: ルールや設定の効果はアブレーションで切り分ける。
- **多重比較を考慮する**: 多数の組合せを試した場合はデータスヌーピングの補正を入れる。
- **棄却も知見として残す**: 効かなかった結果も記録する。

## このリポジトリについて

**方針**: コードと、それを理解するのに必要な最小限の情報（README・手法の説明・軽量な結果要約）のみを置く。検証を再現すればいつでも再生成できる生データ・中間生成物・運用ログは含めない。

- 全組合せの生データ（npz/parquet 等）、大容量な途中経過 CSV、ブートストラップの生サンプル、収集・学習・提出の運用ログ、学習データ・モデル重み・キャッシュはリポジトリに含めていません。各検証の要約（`summary.json`・集計済み CSV 等）のみを残しています。
- 個人的な記録（売買履歴・対戦データ等）は対象外としています。
