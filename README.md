# quant-verification

金融工学の検証プロジェクト集。系統立てたトレード手法・シグナルの有効性を、再現性チェック（ランダム化検定、前半/後半の順位相関、アウトオブサンプル確認など）付きで検証していきます。

## 検証一覧

| ディレクトリ | 対象 | 手法概要 |
| :--- | :--- | :--- |
| [ma-cross-eurusd](./ma-cross-eurusd) | EURUSD H4 の移動平均クロス | SMA/EMA 2本・3本の全周期組合せ（約508万通り）を総当たり検証。循環シフトによるランダム化検定とデータスヌーピング補正、前半/後半の再現性チェックを実施 |
| [kensho-anomaly-decay](./kensho-anomaly-decay) | 決算発表後のアノマリー減衰 | 公表効果（PEAD等）がどの程度のスピードで薄れるかをブートストラップで検証 |
| [seasonality](./seasonality) | 季節性（暖房株・気温相関など） | 気温と関連銘柄の相関、暖房株の季節パターン・空売り検証、決算前後の分解分析 |
| [pair-trading](./pair-trading) | ペアトレード（IEF/TLT, NVDA/AMD） | 共和分・スプレッドの検証スクリプト |
| [report-scoring](./report-scoring) | 検証ログの採点基準の事後検証 | 「結論が後で覆るかどうか」を採点基準（先読みなし・帰無比較・多重比較考慮など）がどれだけ予測するかをブラインド採点・AUCで検証するメタ分析 |

各検証の詳細な手法・結果はそれぞれのディレクトリの README・計画書を参照してください。

## tools/

検証キューの管理スクリプトなど、検証パイプラインを回すための補助ツール。

## このリポジトリについて

- 大容量の中間生成物（全組合せの生データ、npz/parquetファイル等）はリポジトリに含めていません。各検証の `results/` 等には要約（`summary.json` など）のみを残しています。
- 実際の売買記録（損益を含む個人的な取引履歴）は対象外としています。
- 今後 USDJPY や他の時間足・手法の検証を追加予定です。
