# quant-verification

金融工学の検証プロジェクト集。系統立てたトレード手法・シグナルの有効性を、再現性チェック（ランダム化検定、前半/後半の順位相関）付きで検証していきます。

## 検証一覧

| ディレクトリ | 対象 | 手法概要 |
| :--- | :--- | :--- |
| [ma-cross-eurusd](./ma-cross-eurusd) | EURUSD H4 の移動平均クロス | SMA/EMA 2本・3本の全周期組合せ（約508万通り）を総当たり検証。循環シフトによるランダム化検定とデータスヌーピング補正、前半/後半の再現性チェックを実施 |

各検証の詳細な手法・結果はそれぞれのディレクトリの README を参照してください。

## このリポジトリについて

- 大容量の中間生成物（全組合せの生データ、npz/parquetファイル等）はリポジトリに含めていません。各検証の `results/` には要約（`summary.json` など）のみを残しています。
- 今後 USDJPY や他の時間足・手法の検証を追加予定です。
